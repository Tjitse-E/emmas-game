# Moon Meadow Home 1.0.1: plan from Emma's first play

Status: planned on 2026-10-12, revised after validation the same day, not built yet.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer Emma's feedback on Wave A (2026-10-12) with four features and nothing else: harder eggs, hungry wishes and a food tray in the meadow, the lantern walk into the stable at goodnight, and feeding at the mangers before bed. The release is `1.0.1`. Wave B content stays unloaded.

**Architecture:** The same app (`games/moon-meadow-home/`, called `G` below) and the same rules as `docs/v3/plan.md`. Pure rules go in `src/core/`, scenes in `src/scenes/`. No new event type is added: every new act is written with an event that core's validator already accepts (section 3.3). The store's `reconcile` learns to commit one non-fact draft, the maths lift. One new moment kind (`hay-rack`) and one new release value (`1.0.1`) are added once, by the integrator, before the lanes start. Five lanes (eggs, feed, night, integ, art) own disjoint files and build in parallel worktrees. Audio is generated by the integrator before the worktrees are made, so every lane has the clips.

**Tech stack:** unchanged (Node 24.19.0, Svelte 5.57.2, Vite 8.3.4, TypeScript 6.0.3, Vitest 5.0.3, `playwright-cli` 0.1.8 with WebKit, ElevenLabs through `scripts/generate-audio.py`, Codex image generation through the subscription).

**Read first:** `docs/v3/decisions.md` (the heading "2026-10-12, after Emma's first play of Wave A" holds the binding decisions for this plan), `docs/v3/plan.md` Global Constraints and section 2.1 (R1 to R64 still bind), `docs/v3/plan/contracts.ts`. Section 16 of this file lists every validation finding and what was done with it.

## Global constraints

- Everything in `docs/v3/plan.md` Global Constraints still holds: British English only, no Dutch anywhere, unicorns only, no timers, streaks, countdowns, buzzers or red crosses, everything Emma must understand is spoken from a pre-generated clip and shown with pictures, never browser speech.
- Port 8765 and `dist-emma` are Emma's. No lane touches them. Lane ports are 8781 to 8785 (section 4). The gate uses 8766.
- Each lane commits only the paths it owns (`git add <paths>`, never `git add -A`, never `git stash`, never a reset or checkout of a file it does not own). Plain English commit messages, no AI attribution, no em dashes. A commit that fails on `index.lock` is retried after 2 seconds.
- Tests first where practical. `npm test` and `npm run check` stay green for the lane's own files.
- Agents never read, print, source or copy the dotenv file. Scripts load it themselves. Sandbox exceptions (`dangerouslyDisableSandbox: true`): npm install, playwright-cli, codex, ElevenLabs generation, servers on ports.
- Browser checks: `playwright-cli` only, WebKit iPad emulation at 1180 x 820, 1080 x 810 and 1024 x 768, short session names without slashes, screenshots in `$TMPDIR/mmh-shots/`, `mousemove`/`mousedown`/`mouseup` on pulsing elements, sessions closed and servers killed afterwards.
- Older Safari: no CSS `offset-path` and no `Array.prototype.findLast` in runtime code (Safari 15.0). Movement along a path is a list of points animated with `transform`.
- Every subagent runs on `opus`.
- The daily cap of 3 new items per strand (`budget.json` `newPerStrandPerDay`) applies to flows and tests too. A flow that needs more than 3 new maths items moves the clock to the next day and opens a new visit (`setNow`, then `newVisit()`).
- Out of scope (Tjitse, binding): feeding bowls with sharing or halves, labelled food bins, bedtime wishes, all of Waves B and C. Do not build them.

**The store change (I-0, `src/save/game-data.ts`).** Today `reconcile()` passes every candidate through `missingFacts`, which keeps only drafts with a `factKey` (`src/core/world/facts.ts`, "Non-fact drafts are dropped"). `learn.override` has no fact key, so the lift would be silently dropped. The new round:

```ts
for (let round = 0; round < 3; round++) {
  const cands = opts.reconcile(folded.state);
  // Facts are recorded once by key. The maths lift (learn.override, docs/v3/next/plan.md N9) is the only non-fact
  // draft a reconcile returns; folding it sets placement.overridden, so the next round no longer returns it.
  const seen = new Set<string>();
  const overrides = cands.filter((c) => {
    if (c.type !== 'learn.override') return false;
    const k = JSON.stringify([c.op, c.strand, 'step' in c ? c.step : null]);
    if (seen.has(k)) return false;
    seen.add(k);
    return true;
  });
  const extra = [...missingFacts(folded.state.facts, cands), ...overrides];
  if (extra.length === 0) break;
  out.push(...stampAndFold(extra));
}
```

Two devices that both lift before they sync write two equal `set-current` events; the second fold is a no-op for her position (same step, same lists). `src/core/world/facts.ts` does not change.

export function walkRow(i: { layout: StableLayout; names: Map<string, string | null>; eligible: (b: string) => boolean; isDue: (b: string) => boolean }): number | null;
/** The walk picks of that row: due first, then the rest, at most `count`, unique names. */
export function pickWalk(i: { layout: StableLayout; row: number; names: Map<string, string | null>; count: 1 | 2 | 3; eligible: (b: string) => boolean; isDue: (b: string) => boolean; rng: Rng }): { baby: string; name: string; door: number }[];
